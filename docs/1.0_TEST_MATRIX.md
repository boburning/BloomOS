# BloomOS 1.0 Test Matrix

Status values are `not-run`, `pass`, `fail`, or `blocked-physical`. Evidence must
identify build SHA, device/revision, firmware, date, operator, and artifact.

## Automated release gates

| Area | Required evidence |
|---|---|
| Formatting/static analysis | All workflow checks pass |
| Native code | Unit tests and ASan; UBSan where supported |
| Shell boundaries | BusyBox-oriented Bats integration suite |
| Build | Pinned cross-build and reproducibility metadata |
| Packaging | FAT validation, payload manifest, signatures, provenance policy |
| Migration | Fresh, realistic, repeated, malformed, interrupted fixtures |
| UI | 640x480 and 752x560 navigation/layout/golden fixtures |
| Library | 0, 1, 10, 1k, and 10k games; duplicates and malformed data |
| Parsers | Theme, JSON, paths, images, and schema migration fuzz/property tests |
| Performance | Input/render timings, 30-minute shell soak, 500 open/back cycles |
| Privacy | Allowlisted health/support export contains no private data |

## Physical matrix

| Area | Mini V2 | Plus | Flip | V1/V3/V4 external |
|---|---|---|---|---|
| Fresh install and 10 cold boots | not-run | not-run | not-run | not-run |
| Display, input, default UI, long text | not-run | not-run | not-run | not-run |
| Shutdown/reboot/power-loss recovery | partial | partial | partial | not-run |
| Safe Mode and bad-theme recovery | not-run | not-run | not-run | not-run |
| Major system/core launch matrix | not-run | partial-remote | not-run | not-run |
| Video, audio, controls | not-run | blocked-physical | not-run | not-run |
| SRAM/save-state create and restore | not-run | blocked-physical | not-run | not-run |
| GameSwitcher and direct shell return | not-run | partial-remote | not-run | not-run |
| 30-60 minute representative play | not-run | partial-remote | not-run | not-run |
| Onion migration | not-run | not-run | not-run | not-run |
| Update, failed candidate, rollback | not-run | partial | not-run | not-run |
| MainUI absent stable-path run | not-run | not-run | not-run | not-run |
| Settings authority cutover, mutation, and rollback | not-run | pass | not-run | not-run |
| Canonical library import, game index, legacy favorites/recents, and bounded paging | not-run | partial-remote | not-run | not-run |
| Flip lid/suspend policy | n/a | n/a | not-run | n/a |

`partial-remote` proves only the recorded process, memory, file, or health
property. It never proves visible rendering, audio, controls, semantic saves, or
successful state restoration.

## Exit criteria

No stable tag is permitted while an automated gate fails, a P0/P1 remains open,
or a required maintainer-device row is `not-run`. External V1/V3/V4 evidence may
be `blocked-physical`, but stable support claims must then exclude the unproven
revision rather than infer it from V2.
