# Music Player

BloomOS does not currently ship the inherited GMU package. Although GMU itself
is open source, the Miyoo package also contains frontend and decoder plugins,
private codec/rendering libraries, themes, and bundled music without a complete
source and license mapping for every shipped byte.

A music player can return after Bloom assembles the application and its entire
codec stack from pinned, authoritatively licensed sources. Bundled sample media
must also carry explicit redistribution rights. Historical Onion 4.2 usage
documentation remains available in the versioned documentation set.
